# Operations Checklist（要件段階）

## 可用性・信頼性

- [ ] SLO / 許容ダウンタイムの目安はあるか
- [ ] 単一障害点は許容範囲か
- [ ] バックアップ・リストア要件は定義されているか

## 観測性

- [ ] ログ・メトリクス・アラートの最低セットは決まっているか
- [ ] 障害切り分けに必要な相関 ID / トレースはあるか

## デプロイ・変更

- [ ] デプロイ方式（ブルーグリーン、カナリア等）の方針はあるか
- [ ] ロールバック手順は定義されているか
- [ ] 設定・シークレットの更新フローは安全か

## 運用プロセス

- [ ] オンコール・エスカレーション先は決まっているか
- [ ] データ移行・メンテナンスウィンドウは必要か
- [ ] 本番後の定常運用タスク（ローテーション、パッチ）は見えているか

## 出力

運用リスクは `RK-NNN`。運用方針のデフォルトは `AD-NNN`。
