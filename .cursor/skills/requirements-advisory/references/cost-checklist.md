# Cost Checklist（要件段階）

## インフラ・従量課金

- [ ] 想定トラフィック / データ量のオーダーは分かっているか
- [ ] 従量課金コンポーネント（DB、egress、関数呼び出し等）の見積もり軸はあるか
- [ ] スパイク時のコスト上限・抑制策はあるか

## 開発・運用コスト

- [ ] 採用技術の学習コスト・既存スキルとの整合は取れているか
- [ ] マネージド vs 自前ホストのトレードオフは検討したか
- [ ] 運用担当の負荷（オンコール、手動作業）は見積もっているか

## スケール・ライフサイクル

- [ ] 初期コスト最小と将来スケールのバランスは取れているか
- [ ] 不要リソースのライフサイクル（TTL、アーカイブ）はあるか

## 出力

コスト影響が大きい未決は `UD-NNN`（Class B）へ。確定方針は `AD-NNN` で記載。
