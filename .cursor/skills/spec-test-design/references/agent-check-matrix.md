# Agent Check Matrix

Phase 3 の Self-Check Report にそのまま転記する。各項目を ✅ / N/A / ⚠️ で記入し、⚠️ には理由を添える。

## A. 入力・制約の境界値（Input & Constraints）

- [ ] **最小値 / 空の入力:** N=0, 1、空文字 `""`、空配列 `[]`、値が 0 のときの挙動が定義・テストされているか
- [ ] **最大値 / オーバーフロー:** N=10^5, 10^18 等で 32bit/64bit 整数オーバーフローや MLE が起きないか
- [ ] **符号・型:** 負数、小数、ゼロ、重複要素が含まれる可能性を考慮しているか

## B. 特殊なデータ状態・構造（Structural Patterns）

- [ ] **全要素同一 / 偏り:** `[1, 1, 1]` や単一ノード、偏り木など極端な偏りで破綻しないか
- [ ] **順序・ソート:** 昇順、降順、ランダム入力での振る舞い
- [ ] **非連結・サイクル:** グラフや探索で孤立頂点やループが存在する場合の無限ループ対策

## C. 例外系・未達成ケース（Corner & Failure Cases）

- [ ] **解が存在しない場合:** 条件を満たす値がないとき、仕様通りの戻り値（`-1`, `null`, 空配列, 4xx 等）を返しているか
- [ ] **先頭・末尾のアクセス:** 探索対象や境界が index 0 / N-1 に位置する場合のオフバイワン対策

## D. 計算量・再帰深度（Complexity & Resources）

- [ ] **時間計算量:** 最悪ケースで制限時間内に収まるアルゴリズムを選択しているか
- [ ] **スタック深度:** 再帰処理で最大入力深度（例: 10^5）でスタックオーバーフローを起こさないか

## E. API / Worker 固有（該当時のみ）

- [ ] **HTTP ステータス:** 成功・クライアントエラー・サーバーエラーが仕様通りか
- [ ] **認証・認可:** 未認証・権限不足の拒否がテストされているか
- [ ] **外部依存失敗:** KV 未存在、upstream タイムアウト等のエラーパス
- [ ] **空 body / 不正 JSON:** パースエラー時のレスポンス
