# Tree & Graph Patterns

**適用条件:** 木・グラフ・探索・最短経路・連結成分

## 木構造（Tree）

| パターン | 検出目的 | 最小 TC 例 |
|---------|---------|-----------|
| 直線状（Skewed / パス） | DFS スタックオーバーフロー、BST 最悪 O(N) | N ノードが一直線 |
| スター型 | BFS キュー最大サイズ、次数依存処理 | 根 + N-1 葉 |
| 完全二分木 | バランス良好ケース | 高さ h の完全木 |
| 最小構成 | ベースケース | N=1（根のみ）、N=2 |
| 左右非対称 | 片側のみ部分木 | 左のみ / 右のみ |

## グラフ（Graph）

| パターン | 検出目的 |
|---------|---------|
| 非連結 | 孤立頂点、複数連結成分 |
| DAG vs サイクル | トポロジカル順序の破綻 |
| 自己ループ・多重辺 | 辺走査の二重カウント |
| 完全グラフ（Dense） | O(V^2) メモリ・走査 |
| 疎グラフ（Sparse） | E=0, E=V-1 |
| 負の重み | ダイクストラ破綻 |
| 負閉路 | ベルマンフォード要否 |

## テスト設計のヒント

- 頂点・辺の番号付け: 0-index / 1-index を仕様通りに
- 無向 / 有向を明示
- 重み付きの場合: 0 重み、負重みを分離してテスト
