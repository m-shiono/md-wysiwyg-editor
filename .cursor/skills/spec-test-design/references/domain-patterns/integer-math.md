# Integer & Math Patterns

**適用条件:** 大きな整数、剰余、組み合わせ数、浮動小数、オーバーフロー

## 整数オーバーフロー

| パターン | 検出目的 | 例 |
|---------|---------|-----|
| 32bit 境界 | JS number 安全整数 | 2^31-1, 2^31 |
| 64bit / 10^18 | 乗算・累積和 | 10^18 × 10^18 |
| 累積和 overflow | prefix sum | 全要素 10^9, N=10^5 |
| 中間結果 overflow | 完成前の max | 差分 max の途中値 |

## 剰余演算 (mod)

| パターン | 検出目的 |
|---------|---------|
| mod = 1 | 退化 |
| mod = 10^9+7 典型 | 負数 mod 補正 |
| 引き算後 mod | `(a - b + mod) % mod` |
| 除算 mod | 逆元・非互質で undefined |

## 符号・ゼロ

| パターン | 例 |
|---------|-----|
| 負 × 負 | overflow と符号 |
| -0 / 0 | ゼロ除算 |
| abs(MIN_INT) | 符号付き最小値 |

## 数学関数

| パターン | 検出目的 |
|---------|---------|
| GCD(a, 0) | ベース |
| 互質 / 非互質 | 拡張ユークリッド |
| 組み合わせ C(n,k) | n=k, k=0, k>n |
| 階乗 | 0! = 1 |

## 浮動小数

| パターン | 検出目的 |
|---------|---------|
| 0.1 + 0.2 | 丸め誤差 |
| 許容誤差 ε | 仕様で eps 明示 |
| 大きな / 小さな magnitude | underflow |

## 言語別メモ（TypeScript）

- `Number.MAX_SAFE_INTEGER` (2^53-1) 超え → BigInt 検討
- mod 計算前に `BigInt` へ昇格するか testspec に明記
- `Math.floor` vs 整数除法 `/` の差
