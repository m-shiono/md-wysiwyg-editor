# Dynamic Programming Patterns

**適用条件:** 部分問題、ナップサック、状態遷移、最適化

## 必須パターン

| パターン | 検出目的 | 例 |
|---------|---------|-----|
| ベースケース | 遷移起点 | index 0/1、空集合、合計 0 |
| 到達不能状態 | 初期値のまま残る | ∞ / -1 が正しく残る |
| 容量 0 | ナップサック境界 | 何も選べない |
| 全アイテム超重 | 選べないケース | 合計重さ > 容量 |
| 全アイテム余裕 | 全部入るケース | 合計重さ << 容量 |
| 更新順序 | 0-1 vs 無制限の混同 | 同一配列の上書き方向 |

## 1 次元 DP の落とし穴

- **0-1 ナップサック:** 容量を **降順** に更新
- **完全ナップサック（個数無制限）:** 容量を **昇順** に更新
- 逆にすると同一アイテムの重複カウント

## テスト設計のヒント

- 小さな手計算可能な入力で期待値を人手で検証
- 状態数が指数級になる入力は P2 に分類
