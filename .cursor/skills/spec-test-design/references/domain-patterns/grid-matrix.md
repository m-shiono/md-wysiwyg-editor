# Grid & Matrix Patterns

**適用条件:** 2D グリッド、迷路、マトリクス DP/BFS/DFS、座標 (i, j)

## 必須パターン

| パターン | 検出目的 | 例 |
|---------|---------|-----|
| 1×1 グリッド | 最小 | `[['.']]` |
| 1×N / N×1 | 一直線 | 幅 1 または高さ 1 |
| 四隅 | 境界アクセス | (0,0), (0,W-1), (H-1,0), (H-1,W-1) |
| 全マス同一 | 均一 | 全部 `#` または `.` |
| 障害物で囲まれた空間 | 到達不能 | 開始点が isolated |
| 開始 = 終了 | 距離 0 | |
| 到達不能 | 解なし | `-1` 等 |

## 移動ルール別

| ルール | 追加 TC |
|--------|--------|
| 4 方向のみ | 対角不可の確認 |
| 8 方向 | 斜め壁抜け防止 |
| 一方通行 / 壁破壊 1 回 | 状態空間拡張 |

## BFS / DFS 特有

| パターン | 検出目的 |
|---------|---------|
| 最短経路 vs 経路数 | BFS 深さ・visited |
| ループなし迷路 | DFS バックトラック |
| 大きな開領域 | キュー・visited メモリ（P2） |

## tree-graph との使い分け

- **grid-matrix:** 座標 (i,j)、セル属性、迷路
- **tree-graph:** 頂点番号・辺リスト、一般グラフ

両方該当する場合（グリッドをグラフに変換）は **両方読む**。

## テスト設計のヒント

- 0-index / 1-index を仕様通りに
- 入力形式: `H×W` 文字列配列 vs 座標リスト を TC で固定
- H,W = 最大は P2
