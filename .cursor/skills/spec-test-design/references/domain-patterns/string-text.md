# String & Text Patterns

**適用条件:** 文字列操作、部分一致、パース、正規表現、テキスト正規化

## 必須パターン

| パターン | 検出目的 | 例 |
|---------|---------|-----|
| 空文字 | 境界 | `""` |
| 1 文字 | 最小非空 | `"a"` |
| 同一文字連続 | ラン長・圧縮 | `"aaaa"` |
| 空白のみ / 前後空白 | trim 漏れ | `"  "`, `" abc "` |
| 大文字小文字混在 | case  sensitivity | `"AbC"`, `"abc"` vs `"ABC"` |
| 回文 | 対称処理 | `"aba"`, 偶数長回文 |
| 部分文字列 vs 部分列 | 問題定義の取り違え | `"abc"` in `"xxabcyy"` |
| エスケープ文字 | `\n`, `\t`, `\\`, `\"` | |
| Unicode・絵文字 | コードポイント単位 vs 書記素 | `"a\u0301"`, `"😀"` |
| 改行コード混在 | LF / CRLF | `"a\r\nb"` |

## 探索・マッチング

| パターン | 検出目的 |
|---------|---------|
| パターンが先頭 / 末尾 | オフバイワン |
| パターン不一致 | 空結果・-1 |
| 重複マッチ | 非重叠 vs 重叠の仕様 |
| ワイルドカード / regex | `.` `*` 贪婪 |

## API / ドキュメント文脈

| パターン | 例 |
|---------|-----|
| 最大文字数境界 | len = max, max+1 |
| 禁止文字混入 | null byte, 制御文字 |
| HTML / Markdown 混在 | XSS・エスケープ漏れ |

## テスト設計のヒント

- 期待値は **正規化後** か **生文字列** か仕様で固定
- Unicode は NFC / NFD 正規化の有無を確認
- パフォーマンス: 長さ 10^5〜10^6 の単一文字列は P2
