# Binary Search Patterns

**適用条件:** ソート済み配列探索、lower/upper bound、答えの二分探索

## 必須パターン

| パターン | 検出目的 |
|---------|---------|
| 範囲外（小） | 全要素より小さい値 → 見つからない |
| 範囲外（大） | 全要素より大きい値 |
| 重複値 | `[2,2,2,2]` の lower/upper bound |
| N=1, N=2 | ループ終了条件のオフバイワン |
| 先頭一致 | 値が index 0 |
| 末尾一致 | 値が index N-1 |
| 存在しない値 | ソート配列内の隙間 |

## テスト設計のヒント

- `left <= right` vs `left < right` で境界が変わる実装を意識
- 答えの二分探索では「条件を満たす最小/最大」を仕様で固定
