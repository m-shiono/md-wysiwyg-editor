# Prefix Sum & Sliding Window Patterns

**適用条件:** 累積和、差分配列、スライド窓、尺取り法、区間クエリ

## 必須パターン

| パターン | 検出目的 |
|---------|---------|
| 区間 = 全体 | [0, N-1] |
| 区間 = 単体 | [k, k] |
| 負数混入 | 単調性前提の破綻 |
| 全要素条件満たす | 窓サイズ N |
| 全要素条件満たさない | 窓サイズ 0 相当 |
| 先頭・末尾で条件成立 | 境界インデックス |

## テスト設計のヒント

- 累積和: オーバーフロー（大きな値の累積）を P1/P2 で検討
- スライド窓: 条件が「和 ≥ K」等の非単調ケースを負数配列で検証
