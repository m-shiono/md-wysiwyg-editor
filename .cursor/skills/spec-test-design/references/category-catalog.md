# Test Category Catalog

Phase 2 で各カテゴリを検討し、該当テストを最低 1 件（P0/P1）または理由付き N/A とする。

## 1. 基本仕様・正常系（Happy Path）

| パターン | 目的 | 例 |
|---------|------|-----|
| 問題文サンプル | 入出力形式・前提の整合 | 公式サンプル入出力をそのまま |
| 代表的一般ケース | 偏りのない標準データ | 中規模の典型入力 |

## 2. 境界値・制約の極値（Boundary & Extreme Values）

| パターン | 例 |
|---------|-----|
| 制約最小 | N=0,1、`""`, `[]`, 値 0 |
| 制約最大 | N=10^5, 10^18 |
| 符号・数値境界 | 負数、0、偶奇、浮動小数丸め |

## 3. データ構造・配置の特殊パターン（Structural Edge Cases）

| パターン | 例 |
|---------|-----|
| 重複・均一 | 全要素同一、全ユニーク |
| ソート順 | 昇順済み、降順、ランダム |
| グラフ・木 | 非連結、自己ループ、パス、スター、完全グラフ |
| 文字列 | 空白、大文字小文字、回文、1 文字、同一文字連続 |

## 4. 例外・不可能な条件（Corner & Invalid Cases）

| パターン | 例 |
|---------|-----|
| 解なし | `-1`, `null`, 空配列, 404 |
| 先頭/末尾一致 | 探索対象が index 0 または N-1 |
| 不正入力 | 型不一致、範囲外（API の 400） |

## 5. パフォーマンス・負荷（Stress & Complexity）

| パターン | 例 |
|---------|-----|
| 最悪計算量入力 | クイックソート O(N^2)、偏り木 DFS |
| 最大ケース | 制約上限のランダムデータ（P2、`@slow`） |
| 深い再帰 | 深さ 10^5 の木（スタックオーバーフロー検出） |

---

## 優先度の付け方

| 優先度 | 意味 | CI |
|-------|------|-----|
| P0 | サンプル・必須正常系 | 常に実行 |
| P1 | 境界・構造・例外 | 常に実行 |
| P2 | ストレス・最大ケース | `@slow` または別 job |
