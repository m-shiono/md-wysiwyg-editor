# MD WYSIWYG Editor

[English](https://github.com/m-shiono/md-wysiwyg-editor/blob/main/README.md)

VS Code 向けの本格的な WYSIWYG Markdown エディタ拡張機能です。  
ドキュメントを Git でバージョン管理しながら、Word や Excel のように直感的な操作感でリッチな表、画像、ダイアグラム、数式を編集できます。

Extension ID: `mshiono.vsc-md-editor`

---

## 主な機能

### 1. 柔軟な編集・閲覧モード（3点モード）
上部ツールバーからいつでもワンクリックでモードを切り替えられます。
ファイルを開いた直後のデフォルトモードは、VS Code 設定 `md-wysiwyg-editor.defaultMode`（既定値: `visual`）で自由にカスタマイズ可能です。

- **Visual（リッチ編集）**: 装飾や図表をリアルタイムに見ながら編集できる WYSIWYG モードです。見出し（H1〜H6）、太字、斜体、取り消し線、箇条書き、タスクリスト、引用、インラインコード、コードブロック、水平線、表、画像などを直感的に編集できます。
- **Source（テキスト編集）**: Markdown のソーステキストを直接確認・編集できるテキストモードです。表内の Tab 移動・自動整列やリスト自動継続などの入力支援が動作します。
- **Preview（閲覧プレビュー）**: 読み取り専用のリッチ描画プレビューです。Mermaid 図、PlantUML、KaTeX 数式、Marp スライドも美しくレンダリングされます。
- **Default Preview 連携**: ツールバーの `Default Preview` ボタンを押すと、VS Code 標準の Markdown プレビューを同一タブグループ内にすばやく開きます（未保存の差分がある場合は保存を確認します）。

---

### 2. 直感的で強力な表（テーブル）編集
Markdown の表をスプレッドシート感覚で編集できます。GFM パイプ表と HTML 表（リッチセル対応）の2つの形式をサポートしています。

- **右クリックコンテキストメニュー & ツールバー**: 表セル上の右クリックから行・列の追加・削除、表の削除をすばやく実行可能。
- **列アライメント（配置切替）**: 列単位で「左寄せ (`:---`)」「中央寄せ (`:---:`)」「右寄せ (`---:`)」をワンクリックで切り替え。Visual / Preview モードで即座に反映され、Markdown デリミタ行にも正しく往復保存されます。
- **行・列の移動 & 行複製**: カーソル位置の行を上下移動（`Alt+↑`/`Alt+↓`）、列を左右移動（`Alt+←`/`Alt+→`）、現在行の複製（`Shift+Alt+↓`）がキーボードでも操作可能。
- **パイプ整列スタイル切替**: 設定 `md-wysiwyg-editor.table.pipeAlignment` で、列幅に合わせて固定長空白で綺麗に揃える `aligned`（全角文字幅 CJK 対応）と、最小パディングの `compact` を選択可能。Source モードでは `Tab` / `Shift+Tab` によるセル移動＆自動整列に対応。
- **Excel / スプレッドシートからのスマートペースト**: Excel や Google スプレッドシートからコピーした TSV や HTML `<table>` をエディタに直接貼り付けるだけで、自動的に Markdown 表として展開挿入。
- **CSV/TSV ⇄ 表相互変換 & Backlog 連携**: 選択テキストの CSV ⇄ Markdown 表相互変換や、Backlog Wiki・課題形式（`|h`, `LEFT:`, `CENTER:`, `RIGHT:` 等）でのコピー＆ペーストに対応。

---

### 3. リッチな画像編集 & ドラッグ＆ドロップ
- **クリップボード貼り付け**: スクリーンショットや画像を貼り付けると、同一階層の `img/` フォルダへ自動保存（`image-NNNN.ext`）し、Markdown の相対リンクとして挿入。
- **ファイルのドラッグ＆ドロップ挿入**: OS（Finder / エクスプローラー）や VS Code ファイルツリーから画像ファイル（PNG, JPEG, GIF, SVG, WebP）をドラッグ＆ドロップして即座に保存・挿入。
- **リサイズハンドル & プリセット**: Visual モードで画像を選択すると、ドラッグリサイズハンドルおよびサイズプリセットボタン（`25%` / `50%` / `75%` / `100%` リセット）が表示され、幅を直感的に調整可能（サイズ変更時は `<img width="..." />` として往復保存）。
- **配置切替 & Alt 編集ポップオーバー**: 画像の左寄せ / 中央寄せ / 右寄せの切り替えや、Alt テキスト（代替テキスト）の編集をミニポップオーバーから直接編集可能。
- **クリック拡大（Lightbox プレビュー）**: Preview モードでのクリック（または Visual モードでのダブルクリック / 拡大ボタン）で、画像を全画面モーダルで拡大表示。細かな図表も `Escape` キーや背景クリックで快適に確認できます。

---

### 4. ダイアグラム・スライド・数式レンダリング
- **Mermaid リアルタイム描画**: ` ```mermaid ` ブロックを即座にダイアグラムとして描画。ズームイン・ズームアウト、パン、Fit（全体表示）、ELK レイアウト（`@mermaid-js/layout-elk`）、VS Code カラーテーマ連動に対応。
- **PlantUML レンダリング**: ` ```plantuml ` ブロックをローカルの Java / `plantuml.jar` / CLI 環境で高速レンダリング。外部サーバーへ図ソースを送信しない安全設計。環境未検出時は通常のコードブロックとして安全にフォールバックします。
- **KaTeX 数式レンダリング**: ` ```math ` / ` ```latex ` ブロックおよびインライン数式（`$E=mc^2$`）をリアルタイムに美しく描画。
- **Marp スライドプレビュー**: Marp 形式のプレゼンテーションスライドを検出した場合、Preview モード内または専用パネルでスライドレンダリングを提供。

---

### 5. 検索・置換ウィジェット（Find & Replace Widget）
- `Cmd+F` / `Ctrl+F` で検索、`Cmd+H` / `Ctrl+H` で置換ウィジェットを起動。
- Visual、Source、Preview の全モードに対応し、大文字・小文字の区別（`[Aa]`）、単語単位（`[\b]`）、正規表現（`[.*]`）、個別置換・一括置換（Undo 統合）を提供。

---

### 6. ドキュメントエクスポート機能
コマンドパレットまたはエディタタイトルメニューから `Export Document...` を選択し、多彩な形式に出力可能：
- **HTML**: エディタスタイル、ローカル画像（Base64 埋め込み）、Mermaid / PlantUML SVG をすべて内包した単一のスタンドアロン HTML を生成。
- **PDF**: 通常文書の印刷 PDF 化、または Marp スライドの高精度 PDF 出力。
- **DOCX (Word)**: Pandoc または内蔵コンバータによる Word ドキュメント変換。
- **PPTX (PowerPoint)**: Marp スライド文書の PowerPoint プレゼンテーション変換。

---

### 7. スマートな入力・編集支援（エディタアシスト）
- **リスト自動継続**: 箇条書き（`-`, `*`, `+`）や番号付きリスト（`1.`）の行で `Enter` を押すと次行にマーカーを自動挿入（番号は自動インクリメント）。空行で `Enter` を押すとリストを安全に終了。
- **タスクリストのトグル**: `Alt+C` でカーソル行（または選択行）のタスクリスト（`- [ ]` / `- [x]`）を相互に切り替え。
- **書式ショートカット**: 太字（`Cmd+B` / `Ctrl+B`）、斜体（`Cmd+I` / `Ctrl+I`）、取り消し線（`Alt+S`）、インライン数式（`Cmd+M` / `Ctrl+M`）、リンク（`Cmd+K` / `Ctrl+K`）。
- **スマート URL ペースト**: 文字列を選択した状態でクリップボードの URL を貼り付けると、自動的に選択テキストをラベルにした `[選択テキスト](URL)` に変換。
- **目次（TOC）自動生成**: ドキュメント内の見出し（H1〜H6）から階層化目次ブロックを生成し、保存時に自動同期。

---

### 8. 誤編集を防ぐ Readonly モード
ファイル単位で編集ロック（Readonly）を切り替えることができます（`Toggle Readonly Mode`）。ドキュメントの閲覧や誤編集防止に最適です。

---

## 使い方 & 初期設定

### Markdown ファイルを開く
`.md` ファイルを開くと、自動的に本エディタが起動します。

### 既定のエディタに設定する（推奨）
常に本エディタで `.md` ファイルを開きたい場合は、VS Code の設定（`settings.json`）に以下を追加します：

```json
{
  "workbench.editorAssociations": {
    "*.md": "md-wysiwyg-editor.wysiwyg"
  },
  "md-wysiwyg-editor.defaultMode": "visual" // "visual" (リッチ編集) | "source" (テキスト) | "preview" (閲覧)
}
```

### 主な設定項目
| 設定キー | 型 | 既定値 | 説明 |
|---|---|---|---|
| `md-wysiwyg-editor.defaultMode` | string | `"visual"` | ファイルオープン時の初期モード（`visual` / `source` / `preview`） |
| `md-wysiwyg-editor.table.pipeAlignment` | string | `"aligned"` | GFM 表の区切り文字配置スタイル（`aligned`: 固定長空白揃え / `compact`: 最小空白） |
| `md-wysiwyg-editor.plantuml.jarPath` | string | `""` | ローカルの `plantuml.jar` のパス（未設定時は環境変数や PATH を探索） |
| `md-wysiwyg-editor.plantuml.command` | string | `""` | PlantUML 実行コマンド（例: `'plantuml'` や `'java'`） |

## 主なキーボードショートカット

| ショートカット (Mac / Win) | 機能 |
|---|---|
| `Cmd+F` / `Ctrl+F` | 検索ウィジェットを開く |
| `Cmd+H` / `Ctrl+H` | 置換ウィジェットを開く |
| `Alt+↑` / `Alt+↓` | （表内）カーソル行を上下に移動 |
| `Alt+←` / `Alt+→` | （表内）カーソル列を左右に移動 |
| `Shift+Alt+↓` | （表内）現在行を直下に複製 |
| `Tab` / `Shift+Tab` | （表内）次/前のセルへ移動・自動整列（末尾セルで新行追加） |
| `Alt+C` | タスクリストのチェック状態をトグル |
| `Cmd+B` / `Ctrl+B` | 太字トグル |
| `Cmd+I` / `Ctrl+I` | 斜体トグル |
| `Alt+S` | 取り消し線トグル |
| `Cmd+M` / `Ctrl+M` | インライン数式トグル |
| `Cmd+K` / `Ctrl+K` | リンク構文挿入 |
| `Escape` | 検索・置換ウィジェット / Lightbox 画像拡大を閉じる |
