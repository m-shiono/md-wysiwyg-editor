# MD WYSIWYG Editor

[English](https://github.com/m-shiono/md-wysiwyg-editor/blob/main/README.md)

VS Code 向けの WYSIWYG Markdown エディタ拡張機能です。
ドキュメントを Git で管理しながら、Word や Excel のように直感的な操作感でリッチな表、図、画像を編集できます。

Extension ID: `mshiono.vsc-md-editor`

## 主な機能

### 1. 3つの編集・表示モード
エディタ上部のツールバーから、いつでも以下の3つのモードを切り替えることができます。
ファイルを開いた直後は安全のため Edit Raw Text モードで表示されます。

- Editor Preview: 読み取り専用のリッチな描画プレビューです。Mermaid 図や Marp スライドも綺麗にレンダリングされます。
- Edit Rich Editor: 装飾や書式をリアルタイムに見ながら編集できる WYSIWYG モードです。見出し（H1〜H6）、斜体、取り消し線、箇条書き、タスクリスト、引用、リンク、コードブロック、水平線などを直感的に入力できます。
- Edit Raw Text: Markdown のソーステキストを直接確認・編集できるテキストモードです。

### 2. VS Code 標準プレビューとのワンクリック連携
ツールバーの Default Preview ボタンを押すと、VS Code 標準の Markdown プレビューを同一タブグループ内にすばやく開くことができます。編集内容に未保存の変更がある場合は、保存してからプレビューを開きます。

### 3. 直感的な表（テーブル）編集
セルの結合、セル内での改行、箇条書きリスト、チェックボックスの配置など、表計算ソフトに近い柔軟なテーブル編集をサポートします。

### 4. Mermaid 図のリアルタイム描画
` ```mermaid ` ブロックに記述されたダイアグラムをリアルタイムに図として描画します。ズーム、パン、スクロール操作にも対応しています。

### 5. Marp スライドプレビュー
Marp 形式のプレゼンテーションスライドを検出した場合、専用のスライド表示を行います。

### 6. クリップボード画像の簡単貼り付け
クリップボードにある画像をエディタに直接貼り付けると、同一階層の `img/` フォルダへ自動保存し、Markdown の画像リンクとして挿入します。

### 7. 誤編集を防ぐ Readonly モード
閲覧専用として使いたい場合や誤編集を防ぎたい場合に、ファイル単位で編集ロックをかけることができます。

## 使い方

### Markdown ファイルを開く
`.md` ファイルを開くと、自動的に本エディタが起動します。

### 既定のエディタに設定する（任意）
常にこのエディタで Markdown を開きたい場合は、VS Code の設定（`settings.json`）に以下を追加します。

```json
{
  "workbench.editorAssociations": {
    "*.md": "md-wysiwyg-editor.wysiwyg"
  }
}
```
